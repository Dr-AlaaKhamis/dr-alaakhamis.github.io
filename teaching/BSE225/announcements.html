Final Exam
• Final exam will take place on this Thursday May 25, 2017 from 10:00am to 1:00pm.
• Final exam will be a comprehensive exam.
• The exam will include six questions: 1 Question 1- Number Systems and Binary Arithmetic [9 Marks], Question 2- Binary Logic [12 Marks], Question 3- Algorithms [4 Marks], Question 4- Matlab Review [10 Marks], Question-5: Code Debugging [12 Marks] and Question-6: Code Output [13 Marks]. Code debugging means finding mistakes in a given code and code output means writing the expected output of a given code.
• Theoretical parts will be covered through MCQ, complete, True/False questions, give examples, etc.
• Lecture-1 Introduction to Computer Engineering [NOT INCLUDED]
• Lecture-10: Numerical Analysis and Optimization [NOT INCLUDED]
• No formula sheets will be included in the exam booklet.
• Study carefully all the course materials very carefully including lectures and assignments.
Good luck!
