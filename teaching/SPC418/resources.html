Software Packages and Libraries
ROS (Robot Operating System): provides libraries and tools to help software developers create robot applications.
The Open Motion Planning Library): consists of many state-of-the-art sampling-based motion planning algorithms
MoveIt: is state of the art software for mobile manipulation, incorporating the latest advances in motion planning, manipulation, 3D perception, kinematics, control and navigation.
Player/Stage Project: A very popular Free Software robot interface and simulation system, used for mobile robotics research and teaching worldwide.
OpenRAVE: Open Robotics Automation Virtual Environment
RobotinoView: interactive graphical programming and learning environment for festo Robotino.
Microsoft Robotics Developer Studio: Uses a component based approach.
